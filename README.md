# FDM-Picard-FGDSS
Structure-preserving Crank–Nicolson–Ortigueira–Picard finite-difference solver for the fractional generalized Davey–Stewartson system (FGDSS) with Riesz space-fractional derivatives. Python (NumPy/SciPy): conserves the discrete mass and energy exactly, with momentum as a diagnostic. Companion code to a PhD thesis.
